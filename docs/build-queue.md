# طابور بناء كود الديمو

كل جلسة تاخذ **أول مهمة ما معلّم عليها**، تكتب كودها بـ `Assets/_EchoStation/Scripts/`، وتعلّم عليها `[x]`، وتسوي commit و push. **بدون وكلاء فرعيين** حتى نوفّر.
المرجع: `docs/demo-design.md`، و`CLAUDE.md`. وكل سكربت جديد ينضاف لقائمة السكربتات بـ `CLAUDE.md`.

- [ ] 1. **أداة بناء الممر الرمادي** (Editor script): قائمة `EchoStation > Build Greybox Corridor` تبني الممر 14×1.8 م، والزاوية العمياء، والبابين، والمخزن، والـ Anchors، والـ Triggers، وعلي (CharacterController + كاميرا + مصباح + Pulse + Interactor)، والمسجّل، والـ Layers. حتى صاحب اللعبة يجرّب بكبسة وحدة.
- [ ] 2. **المولّد** (`GeneratorPower`): همهمة الأمان، والنيون مربوط بيه، وحدث الانقطاع (3 ثواني صمت) والرجوع، و`AudioMixer` snapshots.
- [ ] 3. **القاتل** (`KillerController`): لقاءات مبرمجة على NavMesh، يسمع النبضة والخطوات (`EchoPulse.OnPulse`)، وحالات: يتمشى / يشك (نَفَسه يختفي) / يدوّر / يمسك. ما يركض ولا يصيّح.
- [ ] 4. **التخبّي وحبس النفس** (`HidingSpot`, `BreathHold`): تحت الميز والمشبّك، وضغط مستمر (أو كبسة من الإعدادات)، والشاشة تعتم، ودگات القلب.
- [ ] 5. **مشهد المسكة** (`CaughtSequence`): 2-3 ثواني، شريط بالأذن، كتم الصوت، سواد، والرجوع لأول الغرفة.
- [ ] 6. **السعلوة** (`SiluwaReflection`): تبين بالزجاج والانعكاس بس، وتختفي إذا اللاعب باوع مباشرة، وقطرة بلا ماي، وما تتحرك قدّام العين.
- [ ] 7. **الطنطل** (`TantalStalker`): يتحرك بس بإطارات الرمش أو لما ما ينشاف، وأقرب كل مرة، وأصوات المكان تختفي وحدة وحدة.
- [ ] 8. **مدير وقت الديمو** (`DemoClock`): ميزانية الـ30 دقيقة، والأحداث المضمونة بالوقت، وسقف 60 ثانية للدورة، وشيل الدورات الفارغة إذا تأخر.
- [ ] 9. **مشهد الصحوة** (`WakeSequence`): أول 60 ثانية بالضبط حسب `demo-design.md` (الصوت قبل الصورة، فتح الجفون، الدگات بالثانية 45، أول نبضة بالثانية 55).
- [ ] 10. **الألغاز الخمسة** (`ClockPuzzle`, `KnockRhythmPuzzle`, `CassetteFlipPuzzle`, `MuffledSearchPuzzle`, `RadioChannelPuzzle`) ويا سلّم المساعدة بلا واجهة.
- [ ] 11. **الأسرار الأربعة** (`SecretTracker`) والكاسيت الخامس وتأثيره على جملة خلف.
- [ ] 12. **النهاية** (`CarEnding`): السيارة، والقفل، والطنطل، والأذان، وثلاث دگات، وخلف (نص وجه)، والاستكان، والسواد، والاسم، وبطاقة قائمة الأمنيات.
- [ ] 13. **الترجمة** (`Subtitles`, `Localization`): عربي وإنگليزي، صغيرة وبلا اسم المتكلم، ودعم RTL (RTLTMPro، رخصته MIT، يتأكد منها).
- [ ] 14. **القوائم** (`WarningScreen`, `PauseMenu`, `OptionsMenu`): تحذير حساسية الضوء، وتقليل الوميض، وحساسية الماوس، والترجمة، وحبس النفس بكبسة.
- [ ] 16. **خامات مصنوعة بالكود** (Editor script `ProceduralTextures`): كونكريت مبلول، وصبغ حكومي بيج مقشّر، وحديد مصدّي، وطين مفطّر، وماي، وقصب. PNG بـ `Assets/_EchoStation/Art/Generated/` ومواد URP جاهزة.
- [ ] 17. **موديلات بسيطة بالكود** (Editor script `ProceduralProps`): حزم قصب، ومسجّل كاسيت، واستكان چاي، ومصطبة، وساعة حايط، وتقويم، ولوحة سيطرة، وبرميل، وفانوس، ومشبّك حديد. و"إنسان رمادي" للقاتل وخلف (low-poly) حتى يتبدل بموديل MakeHuman/Mixamo.
- [ ] 15. **دليل تركيب المشهد** (`docs/scene-setup.md`): خطوات بالعربي لربط كل السكربتات بالمشهد وتجربة الديمو من أوله لآخره.
